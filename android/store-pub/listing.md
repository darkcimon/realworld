Play Console → **스토어 등록정보(기본 스토어 등록정보)** 에 그대로 붙여 넣는다. 글자 수 제한 안에 맞춰 두었다.

## 파일

| 항목 | 파일 | 규격 |
|---|---|---|
| 앱 아이콘 | `app-icon-512.png` | 512×512 PNG |
| 그래픽 이미지 | `feature-graphic.png` | 1024×500 PNG |
| 휴대전화 스크린샷 | `screenshots/01~07.png` | 1080×1920 PNG (2~8장 필요 — 7장 모두 올리면 된다) |

스크린샷 순서가 곧 스토어 노출 순서다. 01(마을)·02(직장)·03(슈퍼카)이 첫 화면에 보이니 그대로 두는 걸 추천.

## 앱 콘텐츠 (정책) — Play Console 설문에 답할 내용

### 광고
- 앱에 광고가 있나요? → **아니요**

### 타겟층 및 콘텐츠
- 타겟 연령 → **13~15세, 16~17세, 18세 이상** 선택 (실제 가입은 만 14세부터 — 13세 미만이 없으니 "가족" 정책 대상 아님)
- 아동의 관심을 끌 수 있나요? → 아니요

### 앱 액세스 권한 (심사자용)
- 로그인 없이 **비회원으로 바로 시작**할 수 있다 → "모든 기능을 별도 액세스 권한 없이 사용 가능"
  (심사자가 막히지 않게: 첫 화면에서 태어난 해·달을 성인으로 고르고 → 비회원으로 시작)

### 계정 삭제
- 계정을 만들 수 있나요? → 예
- 삭제 요청 URL → **https://real-world.up.railway.app/account-deletion**
- 앱 안 삭제 → 사이드 메뉴(☰) → 계정 삭제

### 데이터 보안 (Data safety)

| 질문 | 답 |
|---|---|
| 데이터를 수집하거나 공유하나요? | 수집: 예 / 공유: **아니요** (Railway·Google Gemini·Anthropic은 우리 대신 처리하는 "서비스 제공업체"라 Play 기준 공유가 아님) |
| 전송 중 암호화 | 예 (HTTPS) |
| 삭제 요청 방법 제공 | 예 |

수집 항목 (모두 "수집", "공유 안 함", 처리 목적은 **앱 기능** / 계정 관리):

| 데이터 유형 | 세부 | 필수/선택 | 목적 |
|---|---|---|---|
| 위치 | **정밀한 위치** | 선택 (인연찾기에서 위치 설정할 때만) | 앱 기능 |
| 개인 정보 | 이메일 주소 | 선택 (계정 저장할 때만) | 계정 관리 |
| 개인 정보 | 사용자 ID (닉네임·게임 ID) | 필수 | 앱 기능, 계정 관리 |
| 사진 및 동영상 | 사진 | 선택 (프로필 사진 올릴 때만) | 앱 기능 |
| 메시지 | 기타 인앱 메시지 | 선택 | 앱 기능 |
| 앱 활동 | 앱 상호작용 / 기타 사용자 생성 콘텐츠 | 필수 | 앱 기능 |

수집하지 않음: 금융 정보, 연락처, 기기 ID, 광고 ID, 건강, 오디오, 파일, 캘린더, 웹 기록, 앱 정보·성능(오류 로그).

### 콘텐츠 등급 (IARC 설문)
로또가 무료 응모라 시뮬레이션 도박이 없다. 사용자 간 대화·위치 공유가 있어 낮은 연령으로는 안 나오지만, 청소년 이용가 범위를 기대할 수 있다 (실제 등급은 설문 결과로 정해진다).

| 질문 | 답 |
|---|---|
| 카테고리 | 게임 |
| 폭력·공포·성적 콘텐츠·비속어 | 없음 (욕설은 필터로 막는다) |
| 시뮬레이션 도박 (현금 보상 없는 도박 요소) | **아니요** — 로또는 무료 응모(아무것도 걸지 않는 랜덤 보상) |
| 실제 돈으로 도박 | 아니요 |
