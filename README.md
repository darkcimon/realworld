# 인생 시뮬레이션 게임 (가칭)

미니게임과 실제 연예(인생) 시뮬레이션을 결합한 게임. 학교에서는 실제 교과 내용을 배우고,
사회에 나가서는 직업 활동을 통해 돈을 벌며 살아가는 구조.

> ⚠️ 이 문서는 기획 초안이며, 계속 업데이트될 예정입니다.

---

## 기획 의도

이 게임은 **인생의 축소판**을 구현하면서도, 힘든 현실을 게임 속에서는 보다 쉽게 이룰 수 있게 해주어 사람들에게 희망을 주고자 기획했다.

- 현실은 돈도 없고 아무것도 없는 삶이더라도, 게임에서만큼은 부유하게 산다고 느낄 수 있게 한다.
- 온라인을 넘어서 **오프라인 연애**로 이어질 수 있는 장을 만들어준다.
- 상대에게 마음을 표현(하트)하고 관계를 쌓아가는 경험 자체를 게임의 중요한 축으로 삼는다.

> 💰 이 문서에서 "원" 단위로 표기된 모든 금액(일급, 알바 분급, 로또, 자동차/아파트/명품, 하트/선물/프로필 열람 비용 등)은 실제 현금이 아니라 **게임 내 화폐(게임머니)** 기준이다.
>
> 💱 **환전 정책 (확정)**: 게임머니는 어떤 경우에도 **현금으로 출금·환전 불가**(일방향 원칙). 실제 결제(현금) → 게임머니 충전(캐시샵) 도입 여부와 가격 정책은 추후 별도 논의. (로또 등 게임 내에서 게임머니가 늘어나는 요소가 사행성으로 해석되지 않도록, 환전 자체를 원천 차단하는 것을 최우선 원칙으로 둔다.)

## 1. 계정 시스템

- 계정 생성 없이도 게임 플레이 가능 (비회원 플레이)
- 단, 지금까지 플레이한 내용을 **저장**하려고 하면 "계정을 생성해야 저장할 수 있습니다" 안내를 띄워 회원가입을 유도
- 즉, 비회원 플레이는 세션 한정(또는 임시 저장), 진행 데이터 영구 저장은 회원가입 필수

## 2. 게임 내 주요 시설

- 학교
- 직장
- 알바
- 로또
- 자동차
- 아파트
- 명품샵
- 마트
- 감옥

## 3. 진행 순서 / 접근 제한

- 게임을 처음 시작하면 **학교**만 입장 가능
- 고등학교 3학년을 졸업해야 직장, 알바를 포함한 모든 시설 이용 가능
- 즉 전체 흐름: `학교(초1~고3) → 졸업 → 사회(직장/알바/로또/자동차/아파트/명품샵/마트)`

## 4. 학교 시스템

### 4.1 기본 구조

- 학교는 실제로 뭔가를 배워가는 콘텐츠를 목표로 함 (실제 교과과정 기반 학습)
- 단체 채팅방과 유사한 UI 구조
  - 상위 탭: **초등학교 / 중학교 / 고등학교**
  - 초등학교 탭 안에 1~6학년 방
  - 중학교 탭 안에 1~3학년 방
  - 고등학교 탭 안에 1~3학년 방
- 최초 입학 시 **초등학교 1학년**부터 시작하며, 그 방만 입장 가능 (상위 학년 방은 승급 전까지 잠김)

### 4.2 학습(수업) 진행

학년 방에 입장하면 **개인별 1:1 수업**이 먼저 시작된다. 같은 방(교실)에 다른 학생이 있어도 주제/칠판은 학생마다 분리되는 개인 과외 형태이며, 원하면 언제든 4.2.4의 단체 수업으로 옮겨가 다른 학생들과 함께 이야기를 이어갈 수 있다. 게임을 단순하게 유지하기 위해 정해진 강의/토론 시간 제한은 두지 않는다 — 진급은 오직 4.3의 승급 시험 결과로만 결정되고, 시험은 참여 시간과 무관하게 언제든 응시할 수 있다.

#### 4.2.1 주제 선정
- 학년별로 핵심 개념 주제군(약 6개 내외)을 커리큘럼 범위로 정해두되, 실제 주제는 매 수업마다 **AI 선생님이 그 범위 안에서 동적으로 선정**한다(고정 대본이 아니라 매번 새로 생성)
- 같은 학생에게 최근에 이미 다룬 주제는 되도록 피해 반복을 줄인다

#### 4.2.2 칠판(Blackboard)
- 채팅창 위에 **칠판** 캔버스를 띄우고, AI 선생님이 텍스트·도형(선/사각형/원/화살표 등)으로 구조화된 그리기 명령을 내려 핵심 개념을 시각적으로 정리해준다
- 학생 질문에 따라 칠판 내용이 갱신될 수 있으며, 딱히 바꿀 필요가 없으면 이전 칠판을 그대로 유지한다
- 칠판이 채팅 내용을 가릴 수 있으므로, 학생이 **칠판 보기/숨기기를 직접 토글**할 수 있다

#### 4.2.3 수업 흐름
- 입장하면 AI 선생님이 오늘의 주제를 칠판을 활용해 쉽게 설명한다. 학생은 언제든 질문할 수 있고, AI 선생님이 그 자리에서 바로 답변한다
- 정해진 시간 제한은 없다 — 원하는 만큼 대화하다가, 준비가 되면 **언제든** 4.3의 승급 시험에 바로 응시하거나, 아래 4.2.4의 단체 수업으로 옮겨갈 수 있다

#### 4.2.4 단체 수업 (여러 학생이 함께)
- 언제든 원하면 반 전체가 함께 쓰는 단체 채팅방으로 이동해 다른 학생들과 자유롭게 대화할 수 있다
- 학습 주제 선정 방식 두 가지
  - AI 선생님이 주제를 직접 선정
  - 참여자들의 **투표**로 주제 선정
- AI 선생님은 학생 메시지마다 즉시 답하지 않음 — 참여자가 많아 채팅이 활발할 때 매번 응답하면 과부하가 걸리고 맥락도 끊기기 때문. 대신 참여자들이 **잠시 채팅을 멈추면** 그 사이 오간 대화를 한 번에 읽고 반영해서 응답
- 개인 수업과 달리 칠판은 없다(여러 학생이 함께 보는 자유 대화 공간이라는 성격이 더 강하다)

### 4.3 승급 시험

- 별도의 참여 시간 요건 없이, 해당 방이 잠겨 있지 않은 한 **언제든** 응시할 수 있다
- 승급 시험 방식
  - AI가 해당 학년 수준의 문제를 한 문제씩 출제
  - 참여자가 답변 → AI가 정답 여부 판정
  - 총 10문제 중 **7개 이상 정답** 시 승급(한 학년 진급) 여부를 **본인이 선택** 가능
    - 승급을 원치 않으면 같은 학년에 계속 머물 수도 있음
- **결과 리뷰**: 시험이 끝나면 결과 화면에서 **틀린 문제만 따로 모아**, 문제·내가 쓴 답·정답·왜 그 답이 맞는지 이유(explanation)를 함께 보여준다 — 틀린 이유를 그 자리에서 바로 복습할 수 있게 하기 위함
- **입력 방식**: 승급 시험/배치고사/근무 모두 **4지선다 버튼이 기본**이고, 원하면 "직접 입력하기"로 전환해 서술형으로도 답할 수 있다(정답 판정은 두 방식 모두 느슨한 문자열 비교). 문제에 `(A/B)` 보기가 있으면 2지선다로 표시하고, 숫자 답은 근처 값을, 텍스트 답은 같은 문제은행의 다른 정답을 오답 보기로 쓴다

### 4.3.1 승급 시험 합격 보상 / 배치고사

- **승급 시험 합격 보상**(학년(방)마다 최초 합격 1회만 지급, 재응시로 반복 지급 없음)
  | 학교급 | 보상 |
  |---|---|
  | 초등학교 | 100만원 |
  | 중학교 | 200만원 |
  | 고등학교 | 300만원 |
- **배치고사**: 학년별 승급 시험을 하나하나 거치지 않고 학교급(초/중/고) 단위로 한 번에 졸업하는 지름길
  - 지금 다니고 있는 학교급만 응시 가능(초등 → 중등 → 고등 순서), 이미 졸업했거나 아직 도달하지 않은 학교급은 응시 불가
  - 10문제 중 **8문제 이상** 정답 시 합격 → 해당 학교급 **졸업장**(점수 기준 등급 산정) 즉시 수여 + 다음 학교급 1학년 진학(고등학교면 사회 진입)
  - 합격 보상: 학교급과 관계없이 **300만원 고정**(학교급당 1회 — 졸업 후에는 재응시 불가)
  - 불합격 시 재응시 가능, 결과 화면에서 틀린 문제의 정답과 이유를 복습할 수 있음

### 4.4 프로필

## 5. 감옥 시스템

- 감옥에서도 채팅방 형태로 다른 수감자들과 대화 가능
- 3시간 동안 감옥에 갇혀 밖으로 나갈 수 없음
- **구금 중에는 감옥(채팅) 외의 다른 콘텐츠에 접근할 수 없음** — 학교 수업, 직장/알바 근무, 로또 구매, 소셜(주변 사람 찾기·프로필 열람·채팅·선물·하트 전송 등) 등 감옥 이외의 모든 기능 이용 불가
- 감옥 내에서도 동일한 금지 행위(욕설, 음담패설)를 3회 이상 반복하면 **독방행**
  - 독방에서는 누구와도 소통 불가능
  - 화면은 검은 화면에 타이머만 표시
  - 독방 구금 기간: 1일 (하루 동안 검은 화면 + 타이머만 노출)

### 6.2 근무 및 급여 지급 규칙

- 자정(00:00)에 일급이 지급되지만, **자동 지급이 아니라 실제로 직장 생활(근무)을 수행해야** 지급됨
- 근무 조건
  - 문제를 5개 이상 맞출것.
  - AI가 해당 직업과 관련된 문제를 출제하거나, 본인이 궁금한 내용을 이야기하면 그에 맞춰 AI가 문제를 생성
  - 문제를 **5개** 맞추면 "잔업을 계속할지 / 퇴근할지" 선택 가능
  - 잔업을 선택하면 다시 5문제 단위로 반복 진행
- **입력 방식**: 4.3절과 동일한 이유로 **4지선다 버튼 기본**(구현 완료, 직접 입력 전환 가능). 근무는 하루 최소 5문제 이상을 매일 반복하는 그라인딩 루프이므로 타이핑 마찰이 누적되면 이탈로 이어지기 쉬움

### 6.2.1 직장 상사 NPC (주간 평가 · 승진, 선택지형)

직장(6.2)에는 **박부장**이 있어 근무 기록을 주 1회 평가하고, 결과에 따라 직급(일급 배수)이 오르내린다. 점장(6.3.1)과 같은 구조로, 판단은 **규칙 기반**이고 플레이어는 서버가 내려준 **선택지 버튼**으로만 답하며, 돈과 직급 변경은 서버가 `economy.ts`의 상한 안에서만 실행한다.

- **평가 주기**: 7일. 근무 패널을 열 때 기한이 지났으면 그 기간의 기록으로 평가를 내린다(별도 스케줄러 없음). 평가 결과는 🔔 알림으로도 도착
- **최소 조건**: 평가 기간 중 2일 이상 근무 + 10문제 이상. 기록이 있지만 부족하면 **평가 보류**, 기록이 전혀 없으면(오랜만에 복귀) 벌점 없이 기간만 넘어간다
- **점수(0~100)** = 정답률 60 + 근무일수 25(5일 만점) + 잔업 15(5회 만점) + 면담 태도(±5, 다음 평가에 1회만 반영)
  | 점수 | 등급 |
  |---|---|
  | 90 이상 | S |
  | 75 이상 | A |
  | 55 이상 | B |
  | 55 미만 | C |
- **직급**(직업별로 따로 쌓임): 사원 ×1.0 → 대리 ×1.15 → 과장 ×1.3 → 부장 ×1.5, 정산되는 일급에 배수가 곱해진다
- **승진**: S/A 평가가 **2회 연속**일 때 "승진 심사를 요청합니다"를 고르면 승진(승진 축하금 = 10만원 × 새 직급 단계). 조건 미달이면 거절만 되고 불이익은 없다
- **강등**: C 평가가 **3회 연속**이면 한 직급 강등(사원은 유지)
- **선택지의 영향**: 사과/조언 요청은 다음 평가 점수 +5/+3, 변명은 -5. "무엇을 보완할까요?"를 고르면 가장 부족했던 항목에 맞춘 조언을 준다
- **기준 공개**: 상사 카드에 이번 평가 기간의 실시간 기록(정답률·근무일·잔업)과 예상 점수/등급, 평가 기준 전체를 보여준다

### 6.3 알바 (마트 알바)

- 급여 방식: **분급** — 1분당 만원
- 업무 내용: 마트에 온 손님이 물건을 사면 계산해주기
- 페널티: 계산을 틀리면, **틀린 금액의 5배**만큼 분급에서 차감
  - 예: 계산을 1,000원 틀리면 분급에서 5,000원 차감
- **입력 방식**: 계산 결과(금액)를 직접 산출해서 입력하는 것 자체가 이 알바 콘텐츠의 본질이므로 4지선다로 대체하지 않음(객관식이면 계산 없이 눈대중으로 찍을 수 있어 콘텐츠 의미가 없어짐). 다만 풀 키보드 대신 **숫자 전용 키패드(계산기형 UI)**를 제공해 타이핑 마찰만 최소화(구현 완료). 손님 카트와 정답 금액은 **서버가 발급·보관**하고 클라이언트는 입력 금액만 보낸다

### 6.3.1 점장 NPC (마트 알바, 선택지형)

마트 알바에는 **김점장**이 있어 근무 결과에 반응하고, 플레이어의 행동에 따라 알바의 흐름이 달라진다. 점장의 판단은 **규칙 기반**(같은 행동 → 같은 결과)이고, 플레이어는 서버가 내려준 **선택지 버튼**으로만 답한다(자유 입력 없음). 돈과 상태 변경은 서버가 `economy.ts`의 상한 안에서만 실행한다.

- **평가 시점**: 근무 종료 시. 5건 미만의 짧은 근무는 평가하지 않음
  | 이번 근무 정확도 | 점장 반응 | 신뢰도 |
  |---|---|---|
  | 90% 이상 | 칭찬. 10건 이상이면 **하루 1회** 보너스(건당 1,000원, 최대 3만원) | +5 |
  | 60~89% | 무난 | +1 |
  | 60% 미만 | 경고(틀린 금액·손해액 언급) | -8 |
  | 신뢰도 30 미만 + 경고 3회 누적 | 면담 | - |
- **신뢰도(0~100, 시작 50)와 등급**: 70 이상 "믿음직한 직원" 시급 ×1.2 / 30 미만 "요주의 직원" 시급 ×0.8 / 그 사이 ×1.0. 신뢰도가 오르는 양은 하루 최대 +12
- **선택지**: 응답에 따라 신뢰도가 조금씩 달라짐(예: 사과 +3, 핑계 -1, 계산 요령 문의 +1)
- **특별 근무(바쁜 시간대)**: 신뢰도 50 이상에서 "더 큰 일도 맡겨주세요"를 고르면 제안. 수락 시 다음 10건은 손님 카트가 커지고(4~6개) 시급 ×2(틀리면 페널티는 평소대로). 완료하면 신뢰도 +3과 알림
- 점장 카드에서 **평가 기준을 공개**해 결과가 불공정하게 느껴지지 않게 한다. 근무 후 점장의 말은 🔔 알림으로도 도착한다

### 6.3.2 NPC 랜덤 이벤트 · NPC 간 평판

점장(6.3.1)과 박부장(6.2.1)은 서로의 상태를 참고하고, 가끔 **랜덤 이벤트**를 던진다. 판정과 효과는 전부 규칙 기반이고 수치는 `economy.ts`의 `EVENTS`에 모여 있다(플레이어는 이번에도 서버가 내려준 선택지 키만 보낼 수 있다).

- **NPC 간 평판**: 점장 신뢰도 70↑이면 직장 주간 평가 **+3점**, 30 미만이면 **-3점**. 반대로 직장에서 대리(2직급) 이상이 되면 점장이 승진 소문을 언급하고 축하 이벤트를 준다
- **하루 1회 판정**: NPC별로 하루 한 번만 확률(기본 50%, 환경변수 `NPC_EVENT_CHANCE`로 고정 가능)로 이벤트가 발생한다. 패널을 여러 번 열어도 다시 굴리지 않으며, 답하지 않은 대화가 있으면 새 이벤트는 오지 않는다. 발생 시 🔔 알림도 온다
- **점장 이벤트(근무 시작 시)**
  | 이벤트 | 조건 | 선택지 |
  |---|---|---|
  | 진상 손님 | 항상 | 침착하게 대응 → 다음 3건 시급 ×2, 오차 페널티도 ×2(고위험 고보상) / 점장 호출 |
  | 재고 정리 | 신뢰도 40↑ | 돕는다 → 다음 2건 시급 0, 신뢰도 +4 / 거절 |
  | 승진 소문 | 직장 대리↑ | 감사 / 겸손 |
- **박부장 이벤트(직장 패널 진입 시)**: 긴급 프로젝트(수락 시 이번 평가 기간 잔업 2회 이상이면 **+6점**, 못 채우면 **-4점**) · 회식(참석 시 회식비 5만원 차감, 면담 태도 가산) · 승진 소문
- **임시 효과(modifier)**: 이벤트 선택으로 "다음 N건" 배수가 걸리고, 거래가 끝날 때마다 줄어든다. 알바 화면 점장 카드에 남은 건수가 표시된다
- **안전 장치**: 효과 크기와 금액은 서버 상수 안에서만 실행되고, 잔액이 모자라면 결제 이벤트는 답변 대기 상태로 남는다(돈을 못 냈는데 효과만 받는 일 없음)

### 6.3.3 NPC 대사 LLM 말투 (4단계)

점장·박부장의 **선택지 응답과 하루 첫 인사**는 AI가 캐릭터 말투로 다시 써서 보여줄 수 있다. 판단·금액·효과는 여전히 규칙이 정하고, LLM은 이미 정해진 문장의 **표현만** 바꾼다(`social/npcVoice.ts`, `AIProvider.npcLine`).

- **검증**: 원문의 숫자(금액·배수·건수)가 하나라도 빠지거나 바뀌거나 새로 생기면, 길이가 원문의 2배(최소 80자)를 넘으면, 금지어가 있으면 LLM 문장을 버리고 원문을 쓴다
- **비용 상한**: 유저당 하루 30회, 인사는 유저·NPC당 하루 1회만 생성 후 재사용. 월 예산 초과·키 없음·API 오류 때는 Provider가 원문을 그대로 돌려줘 게임 진행에 영향이 없다(Mock은 항상 원문)
- **범위 밖**: 이벤트 발생 시점의 문구(`evt_*` 안내문)와 알림 문구는 아직 원문 그대로다. 자유 입력 대화는 도입하지 않았다
- 환경변수 `NPC_VOICE_ENABLED=0`이면 끌 수 있고, 한도는 `economy.ts`의 `NPC_VOICE`에서 조정한다

### 6.4 매너 시스템

- 사회인(성인) 유저는 **매너 항목** 점수를 가지며, 초기값은 **100**
- 금지 사항을 어길 경우 매너 항목이 **-1**씩 차감됨
- 매너 항목 점수는 다른 유저에게 프로필 등을 통해 **노출**됨
- **클린 체크**: 개인 프로필에서 클린 체크를 설정하면
  - 매너 항목이 **-10 이상 차감된(90점 이하)** 회원은 목록에 노출되지 않음
  - 해당 회원으로부터 **채팅 요청**도 받을 수 없음

### 6.5 사회인 감옥 시스템

- 사회인도 학교(4.6절)와 동일한 금지 행위(욕설, 음담패설 등) 위반 페널티 규칙을 따름: 1차 경고 → 2차 경고(누적 2회) → 3차 위반 시 **감옥행**
- 구금 기간: **3시간**, 구금 중에는 5장에서 정의한 것과 동일하게 감옥 외 다른 콘텐츠 접근 불가
- 매너 항목은 자동으로 복구되지 않으며, **5,000만 게임머니**를 지불해 매너 항목 차감분을 **0으로 초기화**(= 매너 점수 100으로 복구) 가능

## 11. 프로필 & 소셜(연애) 시스템

### 11.1 프로필 사진

- 기본: 프로필 사진 **1장**만 등록 가능
- **사진첩** 구매(2,000만원) 시 프로필 사진을 최대 **5장**까지 등록 가능

### 11.2 연령 표기 및 매칭 범위 설정

- 실명/신분증 기반 연령 **인증은 하지 않음**. 대신 프로필에 연령대를 **본인이 직접 입력(선택 사항)**
  - 입력하지 않으면 "비공개"로 표시되며, 소셜 목록/매칭 대상에서 상대방의 연령 필터에 걸리지 않을 수 있음(= 상대가 특정 연령대만 보기로 설정했다면 비공개 유저는 노출 안 될 수 있음)
- 각 유저는 **매칭 범위(상대방 연령대 필터)**를 설정 가능
  - 옵션: `10대` / `20대` / `30대` / `40대` / `50대 이상` / `무관` / `직접입력(범위 지정)`
  - 기본값은 `무관`이 아니라 **미설정 상태**로 시작하며, 최초 1회는 반드시 선택하도록 유도(고지 없이 전체 노출되는 상황 방지)
- ⚠️ 자기신고 방식이므로 실제 나이와 다르게 입력하는 것을 시스템적으로 막지는 못함. 이는 인증 절차를 넣지 않기로 한 데 따른 **의도된 트레이드오프**(가입 마찰 최소화)이며, 향후 신고 누적 등 악용 정황이 발견되는 계정에 한해 전화번호 기반 경량 인증 도입 여부는 별도 검토 대상으로 남겨둔다.

### 11.3 주변 사람 찾기

- 위치 기준: 기본값은 실제 **GPS 위치**이며, 게임 내 설정에서 위치를 직접 변경한 경우 **설정한 위치를 우선 적용**
  - 설정 위치 변경은 **하루 1회**로 제한
- 현재 위치를 기준으로 반경 **50km 이내**에 있는 유저 목록 조회 가능, **11.2의 매칭 범위 설정에 따라 필터링**된 목록이 노출됨
- 목록에 있는 유저의 **상세 프로필**을 보려면 **300만원** 필요
  - 프로필 열람권의 유효 시간은 **1시간**
  - 열람권이 유효한 시간 동안에는 해당 유저에게 **채팅**을 걸 수 있음

### 11.4 선물

- 다른 유저에게 선물을 전송하려면 **100만원** 필요

### 11.5 하트(마음 표현) & 맞하트

- 다른 유저에게 **하트**(호감 표시)를 보낼 수 있음 (전송 비용: **50만원**)
- 하트를 **받은** 사람은 보낸 사람의 프로필을 **무료로** 열람 가능
- 하트를 받은 사람이 상대가 마음에 들면 **맞하트**를 보낼 수 있음
- 서로 하트를 주고받으면(맞하트 성립) 그때부터는 **제한 없이 자유롭게** 서로에게 메시지를 보낼 수 있음

### 11.6 차단 기능

- 채팅을 걸어오는 상대가 싫거나 상대를 보고 싶지 않을 때 **차단** 가능
- 차단된 상대는 채팅 요청, 하트 전송, 프로필 열람 등으로 접근할 수 없음

## 11.7 리텐션: 출석 · 일일 퀘스트 · 알림

- **출석 체크**(하루 1회, KST 자정 기준): 연속 출석 1~7일차 보상 20만 / 20만 / 30만 / 30만 / 40만 / 50만 / 100만원, 7일차 다음은 다시 1일차. 하루 빠지면 1일차부터 다시 시작
- **일일 퀘스트**(매일 초기화, 완료 후 직접 "받기"): 진행도는 그날의 실제 활동 기록에서 계산. 유저 상태에 따라 다른 퀘스트가 주어진다
  | 대상 | 퀘스트 | 보상 |
  |---|---|---|
  | 초등학생 | AI 선생님께 질문 1회 / 단체 수업방에서 대화 1회 / 시험(승급/배치고사) 1회 끝까지 응시 | 10만 / 10만 / 20만원 |
  | 중학생 | AI 선생님께 질문 3회 / 단체 수업방에서 대화 1회 / 시험 1회 끝까지 응시 | 15만 / 15만 / 30만원 |
  | 고등학생 | AI 선생님께 질문 5회 / 단체 수업방에서 대화 1회 / 시험 1회 끝까지 응시 | 20만 / 20만 / 40만원 |
  | 신입 사회인(고등학교 졸업 후 3일, KST 졸업 당일 포함) | 직업 구하기(평생 1회) / 마트 알바 계산 1건 / 내 위치 설정 | 50만 / 20만 / 10만원 |
  | 사회인 | 직장 근무 5문제 풀기 / 마트 계산 10건 처리 | 50만 / 30만원 |
- **알림**(우상단 🔔, 30초마다 갱신): 로또 결과(회차당 1건), 월급 지급, 하트 수신, 맞하트 성사. 웹 푸시는 아직 없음
- 그날 첫 접속에 출석 전이면 출석 패널이 자동으로 열리고, 📅 버튼 뱃지로 받을 수 있는 보상 수를 보여준다

## 12. 오픈 이슈 / 추가로 정할 것들 (메모)

- 알바와 정식 직장의 차이(급여, 시간, 승진 여부 등) 미정
- 초/중/고 각 학년별 교과 커리큘럼 범위를 어디까지 반영할지
- 승급 시험 재응시 제한(하루 1회 등) 여부
- 계정 생성 시 기존 비회원 플레이 데이터 이전(마이그레이션) 처리 방식
- 자동차/아파트가 이성 어필용 외에 실제 게임 플레이(이동 편의 등)에도 기능적 효과를 주는지 미정
- 현금 → 게임머니 충전(캐시샵) 도입 여부·가격 정책은 아직 미정 (단, 게임머니 → 현금 환전은 11절 상단 정책대로 확정적으로 불가)
- 차단 시 기존에 성립된 맞하트/대화 이력은 어떻게 처리되는지(관계 해제 여부) 미정
- 클린 체크를 켜지 않은 유저에게는 매너 90점 이하 유저가 그대로 노출/채팅 가능한지 확인 필요
- 자기신고 연령(11.2)과 실제 연령이 다른 것으로 의심되는 신고가 누적된 계정에 대해 전화번호 기반 경량 인증을 요구할지, 요구한다면 어느 시점(가입 시/사회 진입 시/신고 누적 시)에 요구할지 미정
